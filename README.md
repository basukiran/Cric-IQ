# 🏏 CricIQ – Cricket Intelligence Quotient

## 📌 Project Overview

CricIQ (Cricket Intelligence Quotient) is an interactive cricket analytics platform developed using Streamlit, Pandas, and Plotly. The application provides comprehensive insights into cricket data across multiple formats including IPL, ODI, T20I, and Test matches.

The platform enables users to analyze player performance, team statistics, venue trends, match outcomes, live scores, and custom datasets through interactive visualizations and dashboards.

---

## 🎯 Objectives

* Analyze cricket datasets efficiently
* Compare player and team performances
* Visualize batting and bowling statistics
* Explore venue and match trends
* Provide live cricket score updates
* Allow users to upload and analyze their own datasets
